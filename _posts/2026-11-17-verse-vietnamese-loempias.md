Verse Vietnamese loempia's (*Gỏi Cuốn*), ook wel summer rolls genoemd, zijn fris, knapperig en verrassend makkelijk zelf te rollen. In tegenstelling tot gefrituurde loempia's worden deze gemaakt met zacht geweekt rijstpapier en gevuld met rijstvermicelli, knapperige groenten, verse kruiden en garnalen.

## Bereidingswijze

1. **Noedels koken:** Bereid de rijstvermicelli volgens de aanwijzingen op de verpakking (meestal 3–4 minuten wellen in kokend water). Spoel ze direct af onder koud stromend water zodat ze niet aan elkaar plakken en laat goed uitlekken.
2. **Mise-en-place (cruciaal!):** Zet alle gesneden groenten, kruiden, gehalveerde garnalen en noedels in schaaltjes klaar op het aanrecht. Zodra het rijstpapier nat is, moet je snel kunnen werken.
3. **Saus maken:** Roer de pindakaas, hoisinsaus, sojasaus, rijstazijn en knoflook door elkaar. Voeg lepel voor lepel warm water toe tot de saus de dikte van vloeibare yoghurt heeft.
4. **Rijstvel weken:** Vul een grote, ondiepe kom of koekenpan met lauwwarm water. Dompel één rijstvel **5 tot 8 seconden** onder. Het vel moet nog een beetje stug aanvoelen; op je werkblad wordt het vanzelf helemaal zacht.
5. **Beleggen:** Leg het vochtige vel op een schone, licht vochtige snijplank of een groot bord.
   * Leg iets onder het midden een blaadje sla, een plukje vermicelli, en reepjes wortel, komkommer en avocado.
   * Leg daarbovenop (richting de bovenkant van het vel) **3 à 4 halve garnalen** met de roze kant naar beneden — zo schijnen ze mooi door het rijstpapier heen als je klaar bent. Leg er een paar blaadjes munt en koriander bij.
6. **Strak oprollen:** 
   * Vouw eerst de onderkant van het rijstvel over de vulling heen.
   * Vouw daarna de linker- en rechterzijkant naar binnen.
   * Rol de loempia nu zo strak mogelijk naar boven dicht. Door de natuurlijke kleefkracht van het rijstpapier plakt hij vanzelf vast.

## Gouden tips tegen scheuren en plakken

* **Niet te lang weken:** De meest gemaakte fout is het rijstvel te lang in het water houden. Haal het eruit zodra het net buigzaam is, anders scheurt het tijdens het rollen.
* **Voorkom aan elkaar plakken:** Leg de gerolde loempia's op een schaal met een beetje ruimte ertussen, of dek ze af met een schone, licht vochtige theedoek als je ze niet direct serveert.
* **Fris alternatief voor de dipsaus:** Wil je naast de pindasaus een lichte, frisse dip (*Nước Chấm*)? Meng dan 2 el vissaus, 2 el limoensap, 1 el suiker, 3 el water en een fijngehakt rood pepertje en teentje knoflook.

<script>
document.addEventListener('DOMContentLoaded', function () {
  const BASE_PORTIONS = 6;
  const input = document.getElementById('roll-count');
  const btnDecrease = document.getElementById('btn-decrease');
  const btnIncrease = document.getElementById('btn-increase');
  const amounts = document.querySelectorAll('.ingredient-amount');

  function formatFraction(val) {
    const whole = Math.floor(val);
    const rem = val - whole;
    let frac = '';

    if (Math.abs(rem - 0.25) < 0.08) frac = '¼';
    else if (Math.abs(rem - 0.33) < 0.08) frac = '⅓';
    else if (Math.abs(rem - 0.5) < 0.08) frac = '½';
    else if (Math.abs(rem - 0.66) < 0.08) frac = '⅔';
    else if (Math.abs(rem - 0.75) < 0.08) frac = '¾';
    else if (rem >= 0.92) return (whole + 1).toString();

    if (whole === 0 && frac) return frac;
    if (whole > 0 && frac) return `${whole} ${frac}`;
    return whole > 0 ? whole.toString() : '¼';
  }

  function updateIngredients() {
    let portions = parseInt(input.value, 10);
    if (isNaN(portions) || portions < 1) portions = 1;
    const multiplier = portions / BASE_PORTIONS;

    amounts.forEach(el => {
      const base = parseFloat(el.dataset.base);
      const step = parseFloat(el.dataset.step) || 0.5;
      const format = el.dataset.format;

      let raw = base * multiplier;
      let rounded = Math.max(step, Math.round(raw / step) * step);

      if (format === 'fraction') {
        el.textContent = formatFraction(rounded);
      } else {
        // Gebruik een komma voor Nederlandse decimalen en verwijder overbodige nullen
        el.textContent = Number(rounded.toFixed(2)).toString().replace('.', ',');
      }
    });
  }

  btnDecrease.addEventListener('click', () => {
    const current = parseInt(input.value, 10) || BASE_PORTIONS;
    if (current > 1) {
      input.value = current - 1;
      updateIngredients();
    }
  });

  btnIncrease.addEventListener('click', () => {
    const current = parseInt(input.value, 10) || BASE_PORTIONS;
    if (current < 50) {
      input.value = current + 1;
      updateIngredients();
    }
  });

  input.addEventListener('input', updateIngredients);
});
</script>
